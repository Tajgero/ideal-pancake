# ideal-pancake

*My various Python learning projects: ML, Games, Algorithms, Chemometrics*

## About the Repository

This repository collects various Python projects related to data analysis, machine learning, games, and general programming practice. It serves as a personal workshop for continuous learning, experimenting, and improving programming skills.

### ML

Contains machine learning and data science projects, including algorithm implementations, data preprocessing, model training, validation, and visualization. Topics include prediction, classification, clustering, regularization, and model evaluation.

### My_Games_clear_code_potato

A folder with game development projects written in Python. The focus is on clean, readable code ("clear code") and understanding game mechanics, physics, or GUI logic. It includes both basic and advanced gameplay experiments.

### NVIDIA_PCA

A project focused on **Principal Component Analysis (PCA)** performed on an NVIDIA-related dataset (in Excel file). It demonstrates dimensionality reduction, component interpretation, and visualization of patterns or classes within data. 
- Czekanowski diagram,
- PCA,
- Histograms,
- Objects similiarity,
- Features similiarity

### Programming_in_Bioinformatics

Projects and scripts related to bioinformatics and biotechnology — including exercises, algorithms, and biological data processing (sequence analysis, structural analysis, etc.). This folder connects biotechnology with computer science through applied programming.

### SlothBytes_challenges

A collection of **coding challenges** and algorithmic exercises. Each challenge focuses on sharpening problem-solving, logical reasoning, and Pythonic thinking.

### cs50_AI

Contains materials and projects from the **CS50’s Introduction to Artificial Intelligence with Python** course. Topics include search algorithms, heuristics, optimization, machine learning, and neural networks.
Various programs have been changed.

### Other

Miscellaneous projects and prototypes that don’t fit into other categories — useful utilities, experiments, and conceptual drafts for future development.

## Technologies and Tools

* **Programming Language:** Python 3
* **Environment:** Jupyter Notebook, PyCharm
* **Libraries:** `numpy`, `pandas`, `scikit-learn`, `matplotlib`, `seaborn`, `tensorflow`
* **Game development:** `pygame` or GUI libraries
* **Version Control:** Git / GitHub
* **Operating Systems:** Windows with WSL and Linux for cross-platform development
